背景类固醇受体共激活因子（Steroid Receptor Coactivators，SRCs）属于 p160 核受体共激活因子家族，在转录调控、发育、代谢、生殖和疾病中发挥关键作用。然而，SRC 的进化起源及其多样化过程仍缺乏清晰认识。
研究方法本研究采用综合性的比较基因组学方法，考察 SRC-1、SRC-2 和 SRC-3 在生命各域中的进化。研究评估了基于结构域的筛选策略，发现 NCBI Batch Web CD-Search Tool 能够清晰区分 3 个 SRC 家族成员的结构域；同时开展了全基因组分析、LXXLL 基序比较、包含 20,000 余种蛋白的结构域分布分析，以及系统发育分析。
研究结果全基因组分析在脊椎动物中鉴定出 298 个典型 SRC 蛋白，并显示 3 个旁系同源物（paralogs）具有不同的分类群分布。LXXLL 基序比较表明，SRC 蛋白同时具有保守模式和旁系同源物特异性模式，这些模式与功能多样化相关。对超过 20,000 种蛋白（其中包括 4,000 余种含 SRC 相关结构域的蛋白）的分析显示，SRC 相关结构域广泛分布于多样分类群；系统发育分析则表明 SRC-1、SRC-2 和 SRC-3 分别形成独立的单系分支，支持其通过古老基因重复实现分化。
研究意义这些结果支持这样一种假说：广泛分布于不同分类群中的既有蛋白模块，可能通过逐步获得结构域和结构域重组，促成了脊椎动物典型 SRC 蛋白的组装。总体而言，本研究为探究脊椎动物 SRC 蛋白的起源、结构进化和功能分化提供了比较基因组学框架，并提出了可检验的进化历史假说。

背景单细胞RNA测序（scRNA-Seq）数据通常表示为细胞×基因计数矩阵，用于刻画采样细胞中各基因的表达，且这些细胞往往来自包含多种细胞类型或细胞状态的异质性群体。几乎所有scRNA-Seq分析流程都会在聚类前进行基因选择，以去除低变异基因并降低高维基因空间。现有事实标准方法多基于离散度与平均表达量评估高变基因，但这类直接依赖均值-方差关系的方法常受方差不稳定性、下游分析所需最佳基因数目难以确定，以及偏向低丰度高方差基因等问题影响。
研究方法研究提出一种不依赖均值-方差比的新型高变基因选择方法——主成分基因（Principal Genes, PG）方法。该方法利用主成分分析（PCA）的旋转矩阵/载荷（rotations/loadings）为每个基因计算新的变异性评分，即基因主成分得分（Gene Principal Score, GPS），并据此按变异性从高到低对基因排序。为提高计算效率，作者采用增强型隐式重启Lanczos双对角化（Augmented Implicitly Restarted Lanczos Bidiagonalization）方法高效获得与最大方差相关的主成分（PCs），并将高GPS基因用于下游分析，尤其是聚类。
研究结果为评估该方法识别高变基因的性能，研究采用了多种验证策略，包括对带有已知“真实”细胞类型标签的scRNA-Seq数据进行聚类。作者将该方法与基于离散度的高变基因（HVG）选择方法进行比较，并使用灵敏度和调整兰德指数（adjusted rand index, ARI）等指标，在6个真实的带标签scRNA-Seq数据集上开展验证。结果表明，Principal Genes在高变基因选择方面与现有方法相比具有可比性，且在很多情况下表现更优，同时能够基于PCA结果实现超快速基因选择。
研究意义该研究提出了一种基于PCA载荷而非均值-方差关系的高变基因筛选思路，为scRNA-Seq分析中的基因选择提供了替代方案。该方法兼具较好的性能与很高的计算效率，尤其适用于聚类等下游分析任务。
