背景类固醇受体共激活因子（Steroid Receptor Coactivators，SRCs）属于 p160 核受体共激活因子家族，在转录调控、发育、代谢、生殖和疾病中发挥关键作用。然而，SRC 的进化起源及其多样化过程仍缺乏清晰认识。
研究方法本研究采用综合性的比较基因组学方法，考察 SRC-1、SRC-2 和 SRC-3 在生命各域中的进化。研究评估了基于结构域的筛选策略，发现 NCBI Batch Web CD-Search Tool 能够清晰区分 3 个 SRC 家族成员的结构域；同时开展了全基因组分析、LXXLL 基序比较、包含 20,000 余种蛋白的结构域分布分析，以及系统发育分析。
研究结果全基因组分析在脊椎动物中鉴定出 298 个典型 SRC 蛋白，并显示 3 个旁系同源物（paralogs）具有不同的分类群分布。LXXLL 基序比较表明，SRC 蛋白同时具有保守模式和旁系同源物特异性模式，这些模式与功能多样化相关。对超过 20,000 种蛋白（其中包括 4,000 余种含 SRC 相关结构域的蛋白）的分析显示，SRC 相关结构域广泛分布于多样分类群；系统发育分析则表明 SRC-1、SRC-2 和 SRC-3 分别形成独立的单系分支，支持其通过古老基因重复实现分化。
研究意义这些结果支持这样一种假说：广泛分布于不同分类群中的既有蛋白模块，可能通过逐步获得结构域和结构域重组，促成了脊椎动物典型 SRC 蛋白的组装。总体而言，本研究为探究脊椎动物 SRC 蛋白的起源、结构进化和功能分化提供了比较基因组学框架，并提出了可检验的进化历史假说。

背景Magnusiomyces clavatus是一种新兴真菌病原体，主要感染血液科病房住院的免疫功能低下患者。由于其遗传同质性显著，难以开展高分辨率系统发育分析，从而限制了菌株的准确区分，并使医院暴发背景下的流行病学监测更加复杂。
研究方法本研究分析了62个全基因组序列，构建了迄今为止该物种最全面的系统基因组学框架，其中包括来自意大利南部一所大型医院的4个临床和环境新基因组。研究采用基于泛基因组图（pangenome graph）的变异检测策略，对1,624个高质量单核苷酸多态性（single nucleotide polymorphisms, SNPs）进行分析，并结合群体结构、交配型（MATα）及线粒体基因组比较分析。
研究结果研究划分出8个遗传上可区分的分支（A-H），且这些分支能够准确反映该真菌的地理流行病学历史。群体结构分析显示，地理上分离的群体之间存在显著遗传分化，提示其发生了局部多样化；同时，所有菌株中仅检测到MATα特异型（idiomorph），支持M. clavatus具有高度克隆性的特征。比较线粒体基因组分析还发现了43个保守的翻译旁路（translational bypass, byps）元件，并根据特定倒位区域的有无鉴定出4种可能的线粒体型（mitotypes）。
研究意义本研究为这一重要新兴真菌病原体未来的基因组流行病学研究和暴发调查提供了稳健且高分辨率的分析框架。该框架有助于提升对M. clavatus菌株分化、传播格局及医院相关流行病学的解析能力。

背景空间分辨转录组学（spatially-resolved transcriptomics, SRT）能够在保留每个细胞空间位置的同时，以单细胞分辨率测量基因表达，从而联合研究细胞身份与细胞生态位（cellular niche）。现有表征学习方法通常一次只能捕捉其中一个维度，难以同时表征细胞内在身份与空间微环境。
研究方法研究提出了 SQUINT，这是一种基于图的向量量化变分自编码器（graph vector quantized variational autoencoder, VQ-VAE），可通过共享架构为每个细胞学习两个彼此分离的码本：在邻域聚合前量化单细胞嵌入、偏向细胞内在身份的细胞码本，以及在图神经网络（graph neural network, GNN）聚合后量化嵌入、偏向空间上下文的生态位码本。两个分支均采用残差向量量化（residual vector quantization），形成由粗到细的离散标记层级；模型训练结合了各分支的负二项重构目标，以及三个关键组件：切片内余弦邻接损失、细胞潜变量上的跨切片对比损失和用于吸收批次效应的解码器切片协变量。
研究结果在涵盖四种空间测定技术（STARmap、MERFISH、CosMx、Xenium）的三个数据集上，针对生态位识别、细胞类型识别、跨切片整合以及保留区域的空间基因表达插补四项任务，SQUINT 在识别任务上优于或可比于强基线方法，并实现了最忠实的跨切片整合。作者还在 CosMx 人非小细胞肺癌队列中展示了基于编码分布相似性的一步式查询到参考图谱映射能力。
研究意义该方法得到的离散词汇表使组织数据能够被 transformer 风格的基础模型直接使用，并为基于编码分布相似性的图谱映射提供了统一表示。整体上，SQUINT 为同时刻画细胞身份与空间生态位提供了离散、分层且可迁移的表征框架。

背景帕金森病（Parkinson's disease, PD）通常与黑质多巴胺能神经元丢失相关，但在神经元丢失发生之前，许多其他细胞类型也已受到影响。近期研究提示少突胶质细胞（oligodendrocytes）与 PD 早期阶段有关，但其确切作用仍不清楚；而 PINK1 的突变与家族性 PD 相关。
研究方法研究者对 Drosophila Pink1 模型的全脑进行了无偏单细胞测序，并结合细胞类型特异性转录组学分析，观察包裹性胶质细胞（ensheathing glia, EG）中的基因失调。随后在 EG 中特异性下调两个转运因子 Vps35 和 Vps13，以评估其对神经元功能和多巴胺能突触丢失的影响。
研究结果研究发现，Pink1 缺失会导致 EG 出现异常，这种变化类似于神经损伤后 EG 的反应性应答。EG 中存在一组失调基因可作为潜在功能修饰因子；其中，在 EG 中特异性下调同样与 PD 相关的 Vps35 和 Vps13，足以挽救神经元功能并防止多巴胺能突触丢失。结果还表明，神经元中的 Pink1 缺失会触发 EG 的损伤样反应，而 EG 中的 Pink1 缺失又会反过来破坏神经元功能。
研究意义该研究表明，胶质支持细胞在 PD 发病机制中具有关键作用，且 EG 内的囊泡转运（vesicle trafficking）过程参与疾病进展。与细胞器膜相互作用调控相关的囊泡转运组分，可能对维持神经元健康并最终防止多巴胺能突触丢失至关重要。
