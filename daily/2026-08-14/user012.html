Gómez-Ramos Ines, Sánchez-Villegas Rogelio, Mohan Ashwini V, Lavergne Christophe, Cerca José, Márquez-Corro José I, Marques André, Martín-Bravo Santiago, Luceño Modesto, Lucek Kay, Escudero Marcial

https://pubmed.ncbi.nlm.nih.gov/42584994/
Keywords: evolution、genomics、inversion、island、speciation
推荐理由关注染色体结构变异与基因组演化，但对象为植物且非性染色体。
背景染色体重排（chromosomal rearrangements）被认为可通过抑制局部适应基因组区域中的重组来促进物种形成，但其在快速分化过程中如何影响进化速率仍不清楚。该研究聚焦于留尼汪岛上两种姐妹群Carex（Cyperaceae）物种，它们在约0.5百万年前快速分化，并分别占据对比鲜明的热带山地与干旱亚高山生境。
研究方法研究结合染色体水平基因组组装（chromosome-level assemblies）与群体基因组学（population genomics），解析这两种Carex物种的基因组结构及分化格局。作者进一步比较倒位与共线基因组（collinear genome）中的蛋白进化速率，并通过功能分析和环境关联分析识别与适应相关的位点；同时利用偏冗余分析（partial redundancy analyses）评估种内持续生态适应的基因组基础。
研究结果研究发现，基因组分化并非均匀分布，而是集中于特定的大尺度倒位（large-scale inversions）区域。与共线基因组相比，这些结构变异中的基因表现出显著加快的蛋白进化速率，体现为更高的ω；这一模式与重组抑制及随后纯化选择（purifying selection）放松相一致，其作用可能补充甚至超过正选择（positive selection）的信号。功能分析显示，14号和28号染色体上的倒位富集了机械敏感离子通道（mechanosensitive ion channels）和生长素转运（auxin transport）相关基因，支持其促进物种间向干旱环境的生理转变；而种内正在进行的生态适应则在共线基因组中呈现高度多基因性（polygenic）。
研究意义结果表明，基因组结构（genomic architecture）能够主动决定进化速度，染色体倒位可作为“基因组加速器”推动快速遗传演化。该研究提示，受结构变异增强的谱系可能绕过纯化选择的典型约束，从而快速利用空缺的生态机会，并推动生态物种形成。

推荐理由聚焦脊椎动物基因组演化，但未直接涉及性染色体或性别决定。
背景类固醇受体共激活因子（Steroid Receptor Coactivators，SRCs）属于 p160 核受体共激活因子家族，在转录调控、发育、代谢、生殖和疾病中发挥关键作用。然而，SRC 的进化起源及其多样化过程仍缺乏清晰认识。
研究方法本研究采用综合性的比较基因组学方法，考察 SRC-1、SRC-2 和 SRC-3 在生命各域中的进化。研究评估了基于结构域的筛选策略，发现 NCBI Batch Web CD-Search Tool 能够清晰区分 3 个 SRC 家族成员的结构域；同时开展了全基因组分析、LXXLL 基序比较、包含 20,000 余种蛋白的结构域分布分析，以及系统发育分析。
研究结果全基因组分析在脊椎动物中鉴定出 298 个典型 SRC 蛋白，并显示 3 个旁系同源物（paralogs）具有不同的分类群分布。LXXLL 基序比较表明，SRC 蛋白同时具有保守模式和旁系同源物特异性模式，这些模式与功能多样化相关。对超过 20,000 种蛋白（其中包括 4,000 余种含 SRC 相关结构域的蛋白）的分析显示，SRC 相关结构域广泛分布于多样分类群；系统发育分析则表明 SRC-1、SRC-2 和 SRC-3 分别形成独立的单系分支，支持其通过古老基因重复实现分化。
研究意义这些结果支持这样一种假说：广泛分布于不同分类群中的既有蛋白模块，可能通过逐步获得结构域和结构域重组，促成了脊椎动物典型 SRC 蛋白的组装。总体而言，本研究为探究脊椎动物 SRC 蛋白的起源、结构进化和功能分化提供了比较基因组学框架，并提出了可检验的进化历史假说。

背景特发性非梗阻性无精子症（idiopathic non-obstructive azoospermia, iNOA）是男性不育中最严重的类型，但其转录调控机制仍知之甚少。Leydig细胞（Leydig cells, LCs）对雄激素生成和精子发生维持至关重要，但驱动iNOA中LC功能障碍的转录因子尚未被系统表征。
研究方法研究整合了3例iNOA患者和3名正常成年人的睾丸组织公开单细胞RNA测序（single-cell RNA sequencing, scRNA-seq）数据（GSE149512）。采用UMAP聚类、差异表达分析、功能富集、RNA velocity（scVelo）、细胞间通讯分析（CellChat）以及拟时序轨迹重建（Monocle 2、Slingshot）进行综合生物信息学分析，并通过EGR1、FOSB、KLF4与LC标志物CYP17A1的免疫荧光共染在蛋白水平进行验证。
研究结果无偏聚类鉴定出睾丸中的主要细胞类型，并在LC中发现144个差异表达基因，其中转录因子EGR1、FOSB和KLF4上调最显著。功能分析提示这3个因子的上调与应激反应通路相关；拟时序分析显示iNOA的LC停滞于未成熟分化状态，且伴随这3个因子的高表达。虚拟敲除预测其可作为转录抑制因子抑制关键LC功能基因，免疫荧光染色进一步证实它们在iNOA患者LC内的蛋白表达较对照显著升高。
研究意义EGR1、FOSB和KLF4在iNOA的LC中上调，可能通过抑制下游靶基因表达并扰乱支持精子发生的通路，损害LC成熟和雄激素合成。靶向EGR1/FOSB/KLF4轴可能成为恢复iNOA中Leydig细胞成熟与类固醇生成能力的新型治疗策略。

研究意义经验证的进化预测可用于推进保护和农业项目，例如预测哪些种群未来面临灭绝风险、为未来气候优化育种计划，以及在环境变化背景下规划生态系统管理。该框架有助于推动进化生物学向更具预测性的研究范式转变，从而提升人类在变化世界中管理生物多样性和保障粮食安全的能力。

推荐理由涉及发育命运决定与后生动物保守机制，但不聚焦性别决定通路。
背景该研究关注人类胚胎干细胞（hESCs）中中胚层特化的调控机制。标题与摘要指出，这种由机械因素控制的中胚层命运决定机制，与其他后生动物中的相关机制具有保守性。
研究方法Ayad 等人在本期《Developmental Cell》中研究了人类胚胎干细胞（hESCs）的中胚层特化。摘要表明，他们考察了机械应变（mechanical strain）是否可通过依赖 Y654-β-catenin 的机械转导过程诱导该过程。
研究结果研究显示，在人类胚胎干细胞中，机械应变可以诱导中胚层特化，且这一过程依赖于 Y654-β-catenin 介导的机械转导。摘要还指出，这一特征与其他超门代表性后生动物在原肠胚形成过程中通过机械诱导内中胚层（endomesoderm）特化的现象相一致。
研究意义该研究提示，机械力介导的胚层命运决定机制在人类与其他后生动物之间是保守的。这表明机械诱导的内中胚层/中胚层特化可能是后生动物发育中的共同特征。
