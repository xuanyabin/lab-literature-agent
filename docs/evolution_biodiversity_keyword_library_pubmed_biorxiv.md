## 7. 维护规则

- 新增术语优先写英文标准表达，同时保留中文标签。
- 每个主题块至少保留 3 类词: 研究对象、技术方法、科学问题/应用场景。
- PubMed 使用 `[Title/Abstract]` 控制主题词精度，必要时加 MeSH。
- bioRxiv 保持短查询，避免把所有同义词塞进一条式子。
- 每季度检查一次新术语，重点关注 AI 模型、长读长平台、EBP/VGP/B10K/FarmGTEx 项目名变体。
